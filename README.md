# The Road Not Taken
### COP3530 Project 2 - Team Trie-Hards

A choose-your-own-adventure story where your decisions get tracked and compared against 100,000+ simulated users. Built to compare how a Trie and a HashMap handle the same problem, storing and analyzing the paths users take through the story.

## Compile

```bash
g++ -std=c++17 -o game main.cpp Trie.cpp HashMap.cpp
```

## Run

```bash
./game
```
